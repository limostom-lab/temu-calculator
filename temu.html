WED2C 商品分享链接生成器

粘贴商品 SKU（SPU），每行一个 → CJ 换取 Token + 查询 → WED2C 上架 → 取回分享短链。
流程：CJ apiKey → getAccessToken（取 accessToken，缓存复用） → productSku → CJ /product/query（取 pid→cjProductId） → WED2C queryProductInfo(pid)（取 earningsRuleRatio + lowestPrice） → shareProduct(带 storeId 上架) → shareProduct(不带 storeId 取 分享链接)
⚠️ 跨域(CORS)提示：浏览器需直连 developers.cjdropshipping.com 与 business.wed2c.com 两个域， 自定义请求头会触发预检，可能被 CORS 拦截。若报「网络/CORS 错误」，请用免安全策略的浏览器实例： open -na "Google Chrome" --args --user-data-dir=/tmp/cjchrome --disable-web-security，或在「高级」里填 CORS 代理前缀。
CJ getAccessToken 有限频（约 5 分钟/次），Token 已缓存复用，勿频繁刷新。
